# File icons

Material Icon Theme 5.39.0 (github.com/material-extensions/vscode-material-icon-theme), MIT; see LICENSE.
Its icons draw on Material Design Icons by Pictogrammers (pictogrammers.com) and Material Symbols by Google, both Apache-2.0.
Next Term adds mappings (scripts/icon-overlay.json) that reuse these icons.
